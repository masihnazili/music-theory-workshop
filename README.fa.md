# کارگاه هارمونی · Harmony Workshop

یادگیری **عملی** هارمونی و تئوری موسیقی به فارسی، به سبک دولینگو، با **پیانو** یا **گیتار**.

> یک فایل HTML مستقل؛ بدون سرور، بدون ساخت پیچیده و بدون حساب کاربری. پیشرفت فقط در مرورگر خودتان ذخیره می‌شود.

## زبان‌ها

اپلیکیشن از فارسی و انگلیسی پشتیبانی می‌کند. زبان رابط کاربری را از طریق دکمهٔ تغییر زبان در بالای اپ انتخاب کنید. انتخاب زبان در `localStorage` با کلید `hw-lang` ذخیره می‌شود و در اولین اجرا، زبان مرورگر تعیین‌کننده است.

## امکانات

- **۱۰ واحد، ۵۲ درس و بیش از ۵۶۰ تمرین**؛ از نت و فاصله تا ii–V–I، دومینانت ثانویه، آکوردهای آلتره، تغییر کلید و هارمونی منفی.
- درسنامه‌های ساده و تصویری با مثال، نمایش کلاویه‌های پیانو و شکل آکوردهای گیتار.
- تمرین عملی ساز برای تمام ۵۲ درس، با مسیرهای جداگانهٔ پیانو و گیتار.
- تشخیص نت با میکروفون، با استفاده از [Pitchy](https://github.com/ianprime0509/pitchy) و تشخیص‌دهندهٔ داخلی.
- پشتیبانی از کنترلر MIDI از طریق Web MIDI در Chrome و Edge.
- **کارگاه پیانو** با ۱۲ درس تعاملی، نت‌خوانی و ارزیابی ریتم.
- امتیاز تجربه (XP)، استریک روزانه، مرور اشتباهات، آزمون تعیین سطح و تم روز و شب.
- پشتیبان‌گیری از پیشرفت در قالب JSON یا متن و پشتیبانی از کار آفلاین از طریق PWA.

## اجرا

```bash
git clone https://github.com/masihnazili/music-theory-workshop.git
cd music-theory-workshop
python3 -m http.server 8000
```

سپس `http://localhost:8000` را در مرورگر باز کنید.

باز کردن مستقیم `index.html` نیز امکان‌پذیر است؛ اما میکروفون، MIDI و قابلیت‌های آفلاین به `https://` یا `localhost` نیاز دارند.

## ساختار پروژه

```text
index.html            خروجی ساخته‌شده و فایل منتشرشده
src/template.html     پوستهٔ صفحه
src/style.css         استایل‌ها
src/app.js            موتور تئوری، محتوای درس‌ها، رابط، صدا و کارگاه پیانو
src/practice.js       تمرین‌های ساز و شکل آکوردهای گیتار
build.py              ساخت index.html از فایل‌های src/
sw.js, manifest.*     قابلیت‌های PWA و آفلاین
tests/smoke.js        تست دودی با Playwright
docs/CONTENT.md       راهنمای نوشتن درس و تمرین
```

بعد از تغییر فایل‌های `src/`:

```bash
python3 build.py
npm install
npm test
```

`npm install` را فقط در صورت نیاز به نصب وابستگی‌ها اجرا کنید.

## انتشار روی GitHub Pages

فایل `.github/workflows/pages.yml` با هر `push` به شاخهٔ `main` تست‌ها را اجرا می‌کند و سایت را منتشر می‌کند.

در تنظیمات مخزن، مسیر زیر را انتخاب کنید:

**Settings → Pages → Source → GitHub Actions**

## وابستگی‌های بیرونی

| مورد | منبع | مجوز |
|---|---|---|
| فونت‌های Vazirmatn و JetBrains Mono | Google Fonts | SIL OFL |

اگر Pitchy بارگذاری نشود، اپ از تشخیص‌دهندهٔ داخلی استفاده می‌کند. اگر نمونه‌های صدای پیانو در دسترس نباشند، صدای ساده‌تر جایگزین می‌شود.

## محدودیت‌های شناخته‌شده

- تشخیص میکروفون تک‌صدایی است؛ برای تشخیص نت‌های آکورد، آن‌ها را جداگانه و به‌صورت آرپژ اجرا کنید.
- ارزیابی دقیق ریتم با ساز واقعی و تأخیر صدا هنوز به‌طور کامل آزمایش نشده است.
- پیشرفت فقط در مرورگر فعلی ذخیره می‌شود؛ برای انتقال از قابلیت پشتیبان‌گیری استفاده کنید.
- فایل `src/app.js` بزرگ است و تقسیم آن به ماژول‌های کوچک‌تر در نقشهٔ راه قرار دارد.

## نقشهٔ راه

- تشخیص هم‌زمان آکورد با روش‌های کروماتیک و FFT.
- تمرین ریتم با ضربه‌های کاربر و سنجش دقت.
- مرور فاصله‌دار با عنوان «مرور امروز».
- تقسیم `app.js` به ماژول‌های محتوا، موتور و رابط کاربری.
