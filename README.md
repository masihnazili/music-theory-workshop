# کارگاه هارمونی · Harmony Workshop

یادگیری **عملی** هارمونی و تئوری موسیقی به فارسی، به سبک دولینگو، با **پیانو** یا **گیتار**.
A Persian (RTL), Duolingo-style web app that teaches harmony and music theory by having you play, not just read.

> یک فایل HTML مستقل. بدون سرور، بدون ساخت پیچیده، بدون حساب کاربری. پیشرفت فقط در مرورگر خودت ذخیره می‌شود.

## امکانات

- ۱۰ واحد، **۵۲ درس**، بیش از **۵۶۰ تمرین** (انتخابی، ساختن آکورد/گام، گوش‌دادن، تطبیق، لب گروو)، از نت و فاصله تا ii–V–I، دومینانت ثانویه، آلتره، تغییر کلید و هارمونی منفی.
- درسنامه‌ها به زبان ساده و در کارت‌های کوتاه با مثال، کلاویه و شکل آکورد گیتار.
- **تمرین با ساز** برای هر ۵۲ درس، جدا برای پیانو و گیتار (هدف، مراحل، «چطور بفهمی درست بود؟»).
- **تشخیص صدا با میکروفون** (کتابخانهٔ [Pitchy](https://github.com/ianprime0509/pitchy) و تشخیص‌دهندهٔ داخلی) و **کنترلر MIDI** (Web MIDI، فقط Chrome/Edge). چک‌لیست نت‌های هدف در کارت تمرین.
- **کارگاه پیانو**: ۱۲ درس تعاملی با نت‌خوانی و ارزیابی ریتم.
- XP، استریک، مرور اشتباهات، آزمون تعیین سطح، تم روز/شب.
- **پشتیبان‌گیری** از پیشرفت (فایل JSON یا متن) و **کار آفلاین** (PWA) روی GitHub Pages.

## اجرا

```bash
git clone https://github.com/<you>/harmony-workshop.git
cd harmony-workshop
python3 -m http.server 8000      # بعد باز کن: http://localhost:8000
```

`index.html` را مستقیم هم می‌شود باز کرد، ولی میکروفون و MIDI و حالت آفلاین به `https://` یا `localhost` نیاز دارند.

## ساختار

```
index.html            خروجی ساخته‌شده (همین فایل منتشر می‌شود)
src/template.html     پوستهٔ صفحه
src/style.css         همهٔ استایل‌ها
src/app.js            موتور تئوری، محتوای درس‌ها، رابط، صدا، کارگاه پیانو
src/practice.js       تمرین‌های ساز (۵۲ درس × پیانو/گیتار) + کتابخانهٔ شکل‌های گیتار
build.py              ساخت index.html از src/
sw.js, manifest.*     PWA / آفلاین
tests/smoke.js        تست دودی (Playwright)
docs/CONTENT.md       راهنمای نوشتن درس و تمرین
```

بعد از هر تغییر در `src/`:

```bash
python3 build.py
npm install          # فقط بار اول (Playwright)
npm test
```

## انتشار روی GitHub Pages

یک workflow در `.github/workflows/pages.yml` هست که با هر push روی `main` تست می‌زند و سایت را منتشر می‌کند.
در تنظیمات مخزن: **Settings → Pages → Source: GitHub Actions**.

## محدودیت‌های شناخته‌شده

- میکروفون **تک‌صدا** است: آکورد را باید نت‌به‌نت (آرپژ) بزنی. تشخیص هم‌زمان آکورد هنوز نیست.
- ارزیابی دقیق ریتم با ساز واقعی و تأخیر صدا تست نشده است.
- پیشرفت فقط در همین مرورگر است؛ برای جابه‌جایی از پشتیبان استفاده کن.
- `src/app.js` هنوز یک فایل بزرگ است؛ جداکردن به ماژول‌ها در نقشهٔ راه است.

## نقشهٔ راه

- تشخیص هم‌زمان آکورد (کروما/FFT)
- تمرین ریتم با ضربهٔ کاربر و سنجش دقت
- برنامهٔ مرور فاصله‌دار («مرور امروز»)
- جداکردن `app.js` به ماژول‌های محتوا / موتور / رابط
